L'organisation des fichiers

sae-kdou/
    index.html
    base.html
    exploration.html
    indicateurs.html
    personnels.html
    conclusion.html
    rapport.html
    css/
        SAE.css
    images/
        sae/
  • Toutes les pages HTML sont à la racine. Le site est petit, donc les liens entre les pages restent simples, par exemple href="base.html".
  • Il y a une page par partie du sujet, comme ça on retrouve facilement chaque mission.
  • Il n'y a qu'un seul fichier CSS, dans le dossier css. Toutes les pages ont donc la même charte graphique, et pour changer une couleur il suffit de la modifier à un seul endroit.
  • Les images sont dans le dossier images, pour les séparer du code. Les captures de la question 2.1 sont rangées dans le sous-dossier sae.

La charte graphique

  • Couleurs : vert foncé (darkgreen) pour le menu, l'en-tête, le pied de page et les titres, et beige pour le fond.
  • Police : Arial sur tout le site, pour que ce soit simple et lisible.
  • Le contenu de chaque page est dans un cadre blanc, pour qu'il ressorte sur le fond beige.
  • Les requêtes SQL sont dans des blocs gris (balise pre), pour les distinguer du texte.

La structure des pages

  • Chaque page a le même en-tête (header), le même menu (nav) et le même pied de page (footer). Seule la partie main change.
  • Le menu est fixé en haut de l'écran (position: fixed), pour pouvoir changer de page à tout moment.
  • Le pied de page reprend les liens vers toutes les pages et les noms des membres du groupe.
  • Nous avons utilisé des tableaux (table) pour les résultats et des images (img avec un alt) pour les captures Access.

Les outils utilisés

  • PhpStorm pour écrire le code HTML et CSS.
  • GitHub pour partager le site et GitHub Pages pour le mettre en ligne.
  • Le validateur du W3C (validator.w3.org) pour vérifier les pages.

Nous avons seulement utilisé du HTML et du CSS, sans framework. La seule propriété que nous n'avions pas vue en cours est border-radius, qui sert à arrondir les coins des cadres et des boutons.
